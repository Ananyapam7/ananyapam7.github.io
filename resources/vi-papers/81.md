**The obstacle.** Bernoulli classification likelihoods are nonconjugate to Gaussian process priors, so GP regression's closed Gaussian form disappears.

**Mathematical move.** Retain the inducing-variable family \(q(f,u)=p(f\mid u)q_\phi(u)\) and its additive ELBO, but estimate the one-dimensional expected log likelihoods \(\mathbb E_{q(f_i)}\log p(x_i\mid f_i)\) numerically or with appropriate approximations. The global inducing-variable KL remains tractable.

**What changes.** **Likelihood tractability**, while preserving the same scalable variational structure. The lesson is that nonconjugate local factors need not destroy an otherwise useful structured approximation.

Each term is an integral over a single latent function value, even when the data set is large. Gaussian quadrature can therefore handle the nonlinear classification likelihood without a full high-dimensional integral. The sparse representation remains the bottleneck when a small inducing set cannot capture the decision boundary.
