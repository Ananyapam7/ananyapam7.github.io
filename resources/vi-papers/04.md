A score-function gradient can be computed for many distributions, but its noise can make learning slow. For continuous unknowns, there is another source of information: how a sampled value moves when the variational parameters change.

AEVB addresses differentiable generative models with continuous latent variables and a reparameterizable approximation. It combines two changes: a pathwise ELBO-gradient estimator, and an inference network that shares variational parameters across observations. Jointly learning the generative parameters \(\theta\) and inference parameters \(\phi\) gives the VAE construction. The objective remains the ELBO; neither conditional conjugacy nor closed-form CAVI updates are required.

In [BBVI](#paper-3), we differentiate the distribution that produces a draw. Here we express the draw itself as a differentiable function:

\[
\epsilon\sim\nu,\qquad z=T_\phi(x,\epsilon).
\]

When the observation is explicit, write \(q_\phi(z\mid x)\); for fixed \(x\), this is the same \(q_\phi(z)\) used throughout.

The noise law \(\nu\) stays fixed. For a diagonal Gaussian approximation,

\[
z=m_\phi(x)+s_\phi(x)\odot\epsilon,
\qquad \epsilon\sim\mathcal N(0,I).
\]

Hold the same noise draw while changing \(\phi\). The resulting sample moves smoothly, so ordinary differentiation can follow its movement:

\[
\mathcal L(\phi)=
\mathbb E_{\epsilon\sim\nu}[\log w_\phi(T_\phi(x,\epsilon))],
\]
\[
\nabla_\phi\mathcal L=
\mathbb E_{\epsilon\sim\nu}\!\left[
\frac{d}{d\phi}\log w_\phi(T_\phi(x,\epsilon))
\right].
\]

This is a **pathwise gradient**. It uses the slope of the target along the moving sample, rather than only a density comparison at a fixed point.

The paper also introduces shared inference: a network predicts \(m_\phi(x)\) and \(s_\phi(x)\) for each observation. This is **amortization**—learning how to infer across many observations. The model parameters \(\theta\) can also be trained; they remain distinct from the inference parameters \(\phi\), and are held fixed when taking the inference gradient above.

[Stochastic backpropagation](#paper-5) develops a closely related route. [Sticking the Landing](#paper-22) removes a noisy term from this derivative. [Inference suboptimality](#paper-39) asks what is lost when an encoder chooses the local approximation.

**Follow one draw.** For a scalar \(z=m+s\epsilon\) and a fixed smooth function \(f\),

\[
\partial_m\mathbb E[f(z)]=\mathbb E[f'(m+s\epsilon)],
\qquad
\partial_s\mathbb E[f(z)]=\mathbb E[f'(m+s\epsilon)\epsilon].
\]

Increasing \(m\) moves every draw right. Increasing \(s\) moves positive-noise draws right and negative-noise draws left. The derivatives ask whether these movements improve the function. For \(f(z)=z^2\), the sampled mean-gradient is \(2(m+s\epsilon)\), whose average is \(2m\). Holding the noise fixed gives a meaningful comparison between nearby parameter settings.

In a VAE, the same mechanism tells the encoder how changing a latent code affects reconstruction. The ELBO balances expected log likelihood against the KL to the prior: useful codes should explain the observation while keeping the approximate posterior compatible with the generative model.

**Where the difficulties move.** A hard discrete draw does not move smoothly, motivating [Concrete](#paper-13) and discrete estimators. Even with smooth draws, steep decoder derivatives can produce noisy gradients. And a fast encoder can return a suboptimal local distribution: reparameterization makes its gradient tractable, while [amortization-gap methods](#paper-39) address how well its output actually solves inference.
