**The obstacle.** Titsias's collapsed bound still contains an \(N\)-dimensional Gaussian likelihood expression that is inconvenient for data minibatching.

**Mathematical move.** Keep an explicit variational factor \(q_\phi(u)\), while using the exact GP conditional \(p(f\mid u)\):
\[
q_\phi(f,u)=p(f\mid u)q_\phi(u),\quad
\mathcal L=\sum_{i=1}^N\mathbb E_{q_\phi(f_i)}\log p_\theta(x_i\mid f_i)-\mathrm{KL}(q_\phi(u)\|p_\theta(u)).
\]
Now the observation term is additive and can be estimated from minibatches; the KL term is only over the \(M\)-dimensional inducing variables.

**What changes.** **Variational factorization chosen to expose data additivity**, enabling stochastic optimization of a GP. This is a striking example of combining model-specific GP conditional structure with the broadly reusable SVI principle.

The exact conditional appears in both the model and the approximation, so it cancels in the log ratio. Only the inducing distribution needs a separate KL penalty. Intuitively, the inducing variables summarize the function globally while each observation supplies a local correction. Too few or poorly located inducing inputs can miss important function variation; minibatches reduce data cost, not this approximation error.
