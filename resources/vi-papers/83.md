**The obstacle.** Earlier deep-GP approximations often destroy dependence between layers to make analytic integration possible.

**Mathematical move.** Use inducing variables at each GP layer, and draw intermediate latent function values sequentially, preserving conditional dependence across layers in sampled paths. A representative ELBO is
\[
\mathcal L=\sum_i\mathbb E_q\log p_\theta(x_i\mid f_i^{(L)})-\sum_{\ell=1}^L\mathrm{KL}(q_\phi(u^{(\ell)})\|p_\theta(u^{(\ell)})).
\]
Subsample observations and use pathwise Monte Carlo over intermediate layers. This is *doubly stochastic*: data minibatches plus latent-layer draws.

**What changes.** A **structured variational construction** and stochastic estimator tailored to a deep GP. Its reusable principle is to preserve conditional dependence while sampling through a hierarchy.

A draw from layer one becomes the input to layer two, so uncertainty propagates along a sampled path. The inducing factors are still simplified, but intermediate function values are not independently fitted layer by layer. Deep compositions can nevertheless produce noisy gradients or poorly identified layers; increasing depth does not guarantee better calibrated predictions.
