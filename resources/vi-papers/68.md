**The obstacle.** A logistic likelihood breaks Gaussian conjugacy: even a Gaussian prior over regression coefficients gives a non-Gaussian posterior, so CAVI has no convenient Gaussian update.

**Mathematical move.** For \(\sigma(t)=1/(1+e^{-t})\), introduce a local auxiliary number \(\xi>0\) and a quadratic lower bound
\[
\log\sigma(t)\geq \log\sigma(\xi)+\frac{t-\xi}{2}-\lambda(\xi)(t^2-\xi^2),\quad
\lambda(\xi)=\frac{\sigma(\xi)-1/2}{2\xi}.
\]
The right-hand side is quadratic in \(t\). When \(t\) is linear in Gaussian regression coefficients, multiplying by a Gaussian prior produces a tractable Gaussian *surrogate* posterior. Alternate updates of the Gaussian approximation and the auxiliary \(\xi\) values.

**What changes.** This is not a generic Monte Carlo gradient estimator: it changes the computationally troublesome likelihood term by a tractable **additional lower bound**. A valid bound can be conservative.

For binary labels \(y_i\in\{-1,1\}\) and predictors \(v_i\), write the likelihood as \(\sigma(y_i v_i^\top z)\). With prior \(\mathcal N(m_0,\Sigma_0)\), the quadratic surrogate gives
\[
\Sigma^{-1}=\Sigma_0^{-1}+2\sum_i\lambda(\xi_i)v_iv_i^\top,
\qquad m=\Sigma\left(\Sigma_0^{-1}m_0+\tfrac12\sum_i y_iv_i\right),
\qquad \xi_i^2=v_i^\top(\Sigma+mm^\top)v_i.
\]
The auxiliary number adapts each quadratic to the current spread of the linear predictor. It restores computable updates by bounding the difficult term; it does not make the original logistic model conjugate.
