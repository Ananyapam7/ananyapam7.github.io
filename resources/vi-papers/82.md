**The obstacle.** A single Gaussian process is a flexible random function, but layered compositions create latent intermediate outputs whose posterior is difficult.

**Mathematical move.** Introduce latent function values at each layer and a GP prior conditional on preceding-layer outputs. The joint model now contains several latent layers. Variational approximations and inducing variables give a tractable lower bound, with analytic expectations where possible. The crucial change is **the generative model's hierarchy**: the inference problem becomes one of learning uncertain representations across layers.

**What changes.** Primarily the model class and a model-specific variational treatment; it should not be described as a universal new ELBO optimizer.

An intermediate layer is an uncertain representation, not just a deterministic feature transform. The original construction makes these layers tractable with variational independence assumptions and kernel expectations. Those assumptions can lose dependencies between layers; the later doubly stochastic construction changes precisely this part of inference.
