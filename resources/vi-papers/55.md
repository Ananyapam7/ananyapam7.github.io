The ELBO is one way to turn inference into optimization. Operator VI asks how to construct other objectives, including ones that can fit a sampler whose density is unavailable.

Start with a property that the target must satisfy. For a differentiable target on \(\mathbb R^d\), define the Langevin–Stein operator

\[
\mathcal A_\pi f(z)
=\nabla_z\log\gamma(z)^\top f(z)+\nabla_z\cdot f(z).
\]

Here \(f\) is a vector-valued test function. With suitable boundary behavior, integration by parts gives \(\mathbb E_\pi[\mathcal A_\pi f]=0\). The target score uses \(\gamma\), since differentiating removes \(\log Z\).

**Turn a target identity into a test of the approximation.** If samples from \(q_\phi\) consistently violate the identity, they reveal a mismatch. One operator objective is

\[
\mathcal D_{\mathcal F}(q_\phi,\pi)
=\sup_{f\in\mathcal F}
\left(\mathbb E_{q_\phi}[\mathcal A_\pi f(z)]\right)^2.
\]

The chosen test class \(\mathcal F\) controls which discrepancies are visible and must make the optimization well posed. A critic searches for a revealing test; the sampler adjusts to reduce its violation.

Consider a standard normal target in one dimension. Its operator is \(\mathcal A_\pi f(z)=-zf(z)+f'(z)\). The test \(f(z)=1\) detects a nonzero mean; \(f(z)=z\) detects a second moment different from one. These two tests alone cannot distinguish a Gaussian from every other distribution with matching moments. Richer tests can expose discrepancies they miss.

**What changes.** This example replaces reverse KL with a discrepancy built from target identities. It needs target derivatives and variational samples, but no evaluation of \(\log q_\phi\). The paper's broader framework specifies an operator, a test family, and a distance from zero.

It is useful for implicit variational programs. Weak critics can overlook errors, and joint critic–sampler optimization can be difficult. [SVGD](#paper-38) uses a related Stein identity for particle transport; [adversarial VI](#paper-59) instead learns a density ratio to retain an ELBO-based objective.
