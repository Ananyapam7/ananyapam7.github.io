IWAE gives a multisample objective, but a discrete inference network still needs a usable gradient of it. A single learning signal for the whole set does not indicate which sample helped. VIMCO gives each sample a counterfactual baseline built only from the other samples, so credit can be assigned without learning a separate baseline network.

For \(K\) independent draws \(z^{(s)}\sim q_\phi\), let \(w_s=w_\phi(z^{(s)})\). Write \(\ell=\log(K^{-1}\sum_{s=1}^K w_s)\) and \(\bar w_s=w_s/\sum_{r=1}^Kw_r\). With \(\phi\) appearing only in \(q_\phi\), the score-form gradient has contributions \((\ell-\bar w_s)S_\phi(z^{(s)})\). Write \(z^{(-s)}\) for all draws except \(z^{(s)}\). VIMCO subtracts a separate baseline \(b_s(z^{(-s)})\) from \(\ell\) in each contribution. A standard construction replaces \(w_s\) in the baseline by the geometric mean of the other weights. Because \(b_s\) uses only the other draws, \(\mathbb E[b_s S_\phi(z^{(s)})]=0\). This is the multisample version of the baseline idea in [NVIL](#paper-15). [VIMCO-star](#paper-50) revisits the choice of replacement.

**Several samples create a credit-assignment problem.** The log average weight gives the same overall learning signal to every draw. If one draw is excellent and the rest poor, that shared number alone does not tell the encoder which draw deserves credit. VIMCO compares the actual set against a counterfactual set in which one weight is replaced using only its companions.

For \(K\gt 1\), the geometric replacement is

\[
\widetilde w_s=\exp\!\left(\frac1{K-1}\sum_{r\ne s}\log w_r\right),
\qquad
b_s=\log\!\left(\frac{\sum_{r\ne s}w_r+\widetilde w_s}{K}\right).
\]

Then \(\ell-b_s\) measures how much the actual draw changed the set's log average relative to this reference. The additional \(-\bar w_s\) term accounts for the explicit dependence of \(w_s=\gamma/q_\phi\) on the inference parameters. The other draws supply the baseline without requiring a separately trained network.

**When it helps.** It is designed for multisample objectives with discrete latents, where pathwise gradients may be unavailable. It requires several draws, and highly unequal weights can still make credit assignment difficult. Moreover, reducing variance at one sample count does not guarantee favorable scaling as \(K\) grows: [VIMCO-star](#paper-50) shows why the particular replacement choice matters asymptotically.

**What carries forward.** The leave-one-out independence argument is widely reusable for multisample score estimators. The baseline may depend richly on other samples, but must not depend on the particular draw whose score it multiplies.
