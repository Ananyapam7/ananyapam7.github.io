In [SVI](#paper-2), a local factor must work across all plausible values of the global variable without depending on which value actually occurred. That can be restrictive. In a mixture model, for example, an observation's cluster assignment should respond to the sampled cluster locations.

Structured SVI retains the global–local model but changes the approximation:

\[
q_{\phi_g}(z_g)\prod_{i=1}^Nq_{\phi_i}(z_i)
\quad\longrightarrow\quad
q_{\phi_g}(z_g)\prod_{i=1}^Nq_\phi(z_i\mid z_g).
\]

The right-hand side can represent global–local dependence. Local blocks remain conditionally independent given \(z_g\); the paper also retains a factorization between global blocks inside \(q_{\phi_g}\).

**Fit each local problem in the global state that was drawn.** Sample \(z_g\) from its current approximation. For each selected observation, fit or sample a local conditional approximation at that value of \(z_g\). Its sufficient statistics then inform the global update. Different global draws can produce different local explanations of the same observation.

The decomposition makes the benefit precise:

\[
\mathrm{KL}(q_\phi(z)\|\pi(z))
=\mathrm{KL}(q_{\phi_g}(z_g)\|\pi(z_g))
+\sum_i\mathbb E_{q_{\phi_g}}
\mathrm{KL}\!\left(q_\phi(z_i\mid z_g)\|
p(z_i\mid x_i,z_g)\right).
\]

If the local conditionals are exact, the second term vanishes. Global fitting then targets the marginal posterior over \(z_g\), rather than a joint approximation constrained by global–local independence.

**The update changes too.** The paper retains a conjugate-exponential global conditional. With global natural parameters \(\phi_g\), prior parameters \(\lambda_0\), and local statistic estimates \(\widehat s_i\), its minibatch natural-gradient step has the form

\[
\phi_g^{(t+1)}=(1-\eta_t)\phi_g^{(t)}
+\eta_t\!\left[\lambda_0+
V(z_g,\phi_g^{(t)})\frac{N}{|\mathcal B|}
\sum_{i\in\mathcal B}\widehat s_i\right].
\]

The matrix \(V\) accounts for how the sampled global state moves with its variational parameters. The simpler SSVI-A drops this correction, introducing an approximation.

This is valuable when local decisions depend strongly on global uncertainty. It still requires tractable or sufficiently accurate local inference and a suitable global family. Expensive conditional fits or poorly mixed local MCMC can erase the computational benefit. The change is to the **variational dependence and its optimization**, not the model's latent-variable structure.
